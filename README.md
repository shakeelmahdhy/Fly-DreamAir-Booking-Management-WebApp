## 📌 Project Overview

This project was developed as part of the **University of Wollongong** coursework for a real-world client, **FlyDreamAir**. It is a fully functional airline customer management system that allows users to search for flights, manage bookings, and select seats and meals—all within a responsive, user-friendly web interface.

The system is designed to streamline customer interactions, improve the booking experience, and lay the groundwork for future scalability.

---

## 🧩 Key Features

- 🔍 **Flight Search & Selection**  
  Search flights based on origin, destination, and travel date.

- 👤 **User Management**  
  Sign up, sign in, and manage personal information.

- 🎫 **Booking Management**  
  View, confirm, and manage existing bookings with real-time updates.

- 🪑 **Seat & Meal Selection**  
  Customize seat and in-flight meal preferences before confirming your booking.

- 📜 **Ticket Download**  
  Generate and download a ticket upon booking confirmation.

- 📱 **Responsive Design**  
  Fully optimized for desktop and mobile devices.
